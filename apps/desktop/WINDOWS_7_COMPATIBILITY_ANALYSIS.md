# تحلیل فنی و سازگاری رانتایم ویندوز ۷ (سیستم انبار) و ویندوز ۱۱ (سیستم آفیس)

## ۱. صورت مسئله و محدودیت‌های سیستم‌عامل
- **سیستم انبار (Warehouse PC):** ویندوز ۷ (Windows 7 SP1 x86/x64).
- **سیستم آفیس (Office PC):** ویندوز ۱۱ (Windows 11 Pro 64-bit).
- **چالش اصلی:** از تاریخ ژانویه ۲۰۲۳، پروژه کرومیوم (Chromium 110+) و گوگل کلاً پشتیبانی از Windows 7، Windows 8 و Windows 8.1 را به دلیل وابستگی به توابع API جدید ویندوز ۱۰ (مانند `GetDpiForWindow` و به‌روزرسانی‌های امنیتی نوین هسته NT 10.0) قطع کردند. اگر نسخه‌های مدرن Electron (مانند Electron 23 تا 32) روی ویندوز ۷ اجرا شوند، با خطای بحرانی `Entry Point Not Found` در کتابخانه‌های سیستمی کرش می‌کنند.

## ۲. رانتایم منتخب و قطعی
- **نسخه قفل‌شده رانتایم:** **Electron 22.3.27 (آخرین بیلد رسمی سازگار با ویندوز ۷)**
- **مشخصات رانتایم:**
  - Chromium Version: `108.0.5359.215`
  - Node.js Version: `16.20.2`
  - V8 Version: `10.8`
- **سازگاری با ویندوز ۱۱:** الکترون ۲۲.۳.۲۷ روی ویندوز ۱۱ نیز بدون هیچ مشکلی در حالت ۶۴ بیتی با حداکثر سرعت اجرا می‌شود. بنابراین یک کدبیس دسکتاپ مشترک هم انبار (ویندوز ۷) و هم آفیس (ویندوز ۱۱) را پوشش می‌دهد.

## ۳. دیتابیس محلی در دسکتاپ
- از SQLite محلی (`better-sqlite3` یا SQLite3 محلی) متصل به دایرکتوری داده کاربر (`%APPDATA%/MGasWarehouse/database.sqlite`) استفاده می‌شود.
- در سیستم انبار (Windows 7): فایل در مسیر:
  `C:\Users\<User>\AppData\Roaming\MGasWarehouse\warehouse.sqlite`
- در سیستم آفیس (Windows 11): فایل در مسیر:
  `C:\Users\<User>\AppData\Roaming\MGasWarehouse\office.sqlite`

## ۴. معماری همگام‌سازی آفلاین
- هر دو نسخه دسکتاپ به یک لایه ذخیره‌سازی محلی و صف همگام‌سازی (`sync_queue`) مجهز هستند.
- در زمان قطعی اینترنت، برنامه بلاک نمی‌شود و تمام تراکنش‌ها (ورود/خروج، فاکتور، ایجاد کالا، ویرایش مشتری) در دیتابیس محلی ذخیره شده و شناسه رویداد یکتا در صف باقی می‌ماند.
- با برقراری مجدد شبکه اینترنت، ماژول SyncClient به صورت خودکار تغییرات را به API مرکزی کلادفلر ورکر ارسال و نسخه نهایی را به‌روزرسانی می‌کند.
